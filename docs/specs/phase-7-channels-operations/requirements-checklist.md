# Requirements Quality Checklist

## Requirement ID Coverage

- [x] All requirements use REQ-XXX format.
- [x] IDs are unique and sequential.

## Testability

- [x] Every requirement is independently testable.
- [x] Acceptance scenarios use Given-When-Then form.

## Completeness

- [x] Scope baseline is complete.
- [x] User scenarios are prioritized P1-P3.
- [x] Functional requirements cover Internet Banking, Admin, Teller, Audit, Notification and Reporting.
- [x] Success criteria are measurable.

## Constitution Alignment

- [x] Owning services enforce authorization.
- [x] Schema ownership and read boundaries are explicit.
- [x] Notifications and reports cannot alter financial state.
- [x] Idempotency and auditability are explicit.
- [x] Broker, provider and API Gateway selections remain unresolved.
