# Lộ trình phát triển

## Giai đoạn 1: Backend cốt lõi

Xây dựng nền tảng backend và các API để ứng dụng giao tiếp với hệ thống.

- Java và Spring Boot
- REST API
- JPA và PostgreSQL

## Giai đoạn 2: Nghiệp vụ tài chính

Đảm bảo các giao dịch tài chính chính xác, nhất quán và an toàn.

- ACID và quản lý transaction
- Locking
- Double-entry ledger
- Idempotency

## Giai đoạn 3: Bảo mật

Kiểm soát quyền truy cập và lưu lại hoạt động quan trọng trong hệ thống.

- Spring Security và JWT
- RBAC
- Audit logging

## Giai đoạn 4: Hệ thống phân tán

Hỗ trợ xử lý dữ liệu và sự kiện giữa nhiều thành phần trong hệ thống.

- Redis và Kafka
- Outbox Pattern
- Event-driven Architecture

## Giai đoạn 5: Vận hành production

Chuẩn bị hệ thống để triển khai, theo dõi và xử lý tải trong môi trường thực tế.

- Testing
- Docker và CI/CD
- Monitoring
- Load testing
